## What I do

- Generate API contracts from code or requirements
- Validate existing API behavior for completeness and consistency
- Enforce consistent naming conventions across endpoints
- Standardize error response formats and status codes
- Define pagination, filtering, and sorting patterns

## When to use me

Use this skill when designing API routes, server actions, REST endpoints, or frontend/backend data contracts.
